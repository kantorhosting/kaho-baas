# Security Policy

Kaho BaaS handles authentication and user data, so we take security seriously. Thank you for helping keep Kaho and its users safe.

## Supported Versions

Kaho BaaS is in early development and has no stable release yet. Security fixes are applied to the `main` branch only.

| Version | Supported |
|---------|-----------|
| `main`  | ✅        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, Pull Requests, or Discord.**

Send your report by email to **[security@kantorhosting.com](mailto:security@kantorhosting.com)**. Please include as much of the following as you can:

- The type of issue (e.g. authentication bypass, SQL injection, data exposure)
- The affected endpoint, file, or component
- Step-by-step instructions to reproduce the issue
- A proof of concept, if possible
- The impact, and how an attacker could exploit it

## What to expect

- We will acknowledge your report within **3 business days**.
- We will investigate and keep you informed of our progress.
- Once the issue is fixed, we will publish an advisory and credit you for the discovery, unless you prefer to remain anonymous.

Please give us reasonable time to fix the issue before disclosing it publicly, and avoid accessing or modifying data that does not belong to you while researching.
